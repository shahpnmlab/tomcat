<objective>
Strip the `_preali` suffix inside `extract_basename()` so that `tomo001_preali.mrc` resolves to the canonical name `tomo001` — the same name produced by `tomo001_rec.mrc`. This prevents `search_tomograms()` from creating a duplicate catalogue entry for the tilt-series file.

Purpose: A researcher whose data directory contains both `tomo001_rec.mrc` and `tomo001_preali.mrc` currently sees two catalogue rows: `tomo001` and `tomo001_preali`. After this fix they see one row: `tomo001`. The tilt-series file selection priority (`_preali.mrc` > `_ali.mrc`) is already correct in `FileLocator.EXTENSIONS['tiltseries']` and requires no change.

Output: Modified `tomcat/utils/file_utils.py` with `_preali` and `_preali.mrc` added to the suffix-stripping logic in `extract_basename()`.
</objective>
